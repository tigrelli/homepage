이 문서는 TFT_Hideout_WBS.xlsx의 98개 TASK를 기준으로 실제 개발 진행 상태를 추적하는 살아있는 문서다. 클로드 코드와 PM은 새 기능을 개발할 때 WBS 원본이 아니라 이 문서를 기준으로 다음 작업을 정하고, 완료 여부를 갱신한다.

갱신 규칙 (CLAUDE.md 3장과 동일): 클로드 코드가 TASK를 구현 → 단위 테스트 작성·통과 → 자체 검증 → PM에게 확인 요청 → PM이 승인한 뒤에만 아래 표의 상태를 완료로 변경하고 PM확인/커밋 컬럼을 채운다. PM 확인 전에는 상태를 진행중으로 유지하고, git 커밋·push도 하지 않는다.

테스트 요구사항 컬럼: 각 TASK별 구체적인 단위/통합 테스트 항목은 TFT_Hideout_WBS.xlsx의 테스트 요구사항 컬럼(K열)을 참고한다. 여기서는 상태 추적에 집중하기 위해 생략했다.
