1-1. 실제 네비게이션 메뉴 구성 (구현 완료 기준)

위 1장 "전체 메뉴 트리"는 최종 완성 시점의 계획도다. 여기 표는 지금 화면에 실제로 노출되는 사이드바 메뉴만 담는다 — 아직 안 만든 화면으로 가는 링크를 넣어서 죽은 링크를 만들지 않기 위함. 코드 상 원본은 apps/main/web/app/(app)/nav-items.ts이며, 새 화면(F-코드)이 완료될 때마다 이 표와 nav-items.ts 둘 다 같이 갱신할 것.

메뉴 라벨 경로 상위 메뉴 대응 F-코드
홈 / - F-5-1 (요약 카드) + F-1-8-2(월별추이) + F-1-8-3(카테고리별) + F-3-1-1(지출분류별, 현금/카드 대분류+카드사명별) + F-3-1-2(지출처 Top 10) + F-3-1-3(상세항목 Top 10 + 지출처별 드릴다운) + F-3-1-4(품목×단위 평균단가 추이)
지출 입력 /expenses/create - F-1-1-4
지출 내역 /expenses - F-1-1-11
예산 관리 /budgets - F-4-1
관리비 명세서 /utility-bills/upload - F-1-2-1 (2차 개발 TASK ID는 F-2-1-1~F-2-1-3 — WBS 2차 §4 표기법 참고)
명세서 업로드 /utility-bills/upload 관리비 명세서 F-1-2-1
명세서 통계 /utility-bills/stats 관리비 명세서 F-1-2-3 (총액 불일치 알림 아이콘은 F-1-2-5)
명세서 이력 /utility-bills/history 관리비 명세서 F-1-2-6 (2차 개발 TASK ID는 F-2-4-4)
설정 /settings - F-3-4
지출분류 관리 /settings/payment-methods 설정 F-1-1-1
지출항목 관리 /settings/categories 설정 F-1-1-2
지출처 관리 /settings/vendors 설정 F-1-1-3
품목 관리 /settings/items 설정 F-1-1-8 (F-1-6-1, 목록 조회만)
동의어 사전 관리 /admin/synonyms - F-1-1-13 (운영자 전용 — ADMIN_EMAILS 화이트리스트에 없으면 사이드바 비노출 + 직접 접근 시 /로 리다이렉트)

레이아웃 구조: 상단바(로고 + 알림 아이콘 자리 — 알림 기능 자체는 미구현) + 좌측 사이드바(위 메뉴) + 우측 콘텐츠 영역. 모바일에서는 사이드바가 드로어(하단이 아닌 좌측 슬라이드 오버레이)로 전환된다.

F-1-1-8 상세항목 마스터 관리(품목 관리 화면) 1-1⑤ 내 품목 목록 조회, 별칭 추가, 수동 병합(merge)

F-1-1-12 지출 수정/삭제 1-1, 4 기존 트랜잭션 수정(상세 포함)/삭제
F-1-1-14 지출 내역 캘린더 조회 + 빠른 입력 1-1, 4 (2026-07-04 백로그 B-7 채택) 월별 캘린더 그리드에 일자별 지출 카드 나열, /expenses 화면에서 목록↔캘린더 토글로 진입. 날짜 셀의 "+"로 레이어 팝업을 열어 그 날짜를 기본값으로 바로 지출 입력, 저장 즉시 캘린더에 반영. 캘린더의 기존 지출 카드를 클릭해도 페이지 이동 없이 동일한 레이어 팝업으로 수정/삭제(F-1-1-12와 동일 기능을 팝업으로 재사용) 가능

코드 기능명 설명 단계
F-1-2-1 명세서 업로드 관리비 고지서 사진/PDF 업로드 → OCR 추출 → 최초업로드/재업로드(형식동일)/형식변경 자동 분기 → 등록. 동일 월 기존 등록(수동/업로드) 존재 시 차단 또는 재업로드 확인 팝업 처리 2단계
