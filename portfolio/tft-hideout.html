프로젝트 개요

TFT(전략적 팀 전투)의 게임 메타 정보는 패치에 따라 지속적으로 변경되며, 필요한 정보를 확인하려면 여러 웹사이트와 커뮤니티를 탐색해야 합니다.

TFT Hideout은 조합, 아이템, 증강체 등 게임 데이터를 하나의 구조로 정리하고, 웹 탐색과 AI 챗봇을 통해 제공하는 서비스입니다.

본인과 소규모 지인 사용을 대상으로 제품 범위를 정의하고, Claude Code와 협업해 기획부터 구현·검증까지 진행했습니다.

핵심 과제 02

AI 응답의 신뢰성 설계

AI 챗봇은 자연스러운 문장을 생성할 수 있지만, 그 내용이 항상 정확한 것은 아닙니다.

특히 패치에 따라 변경되는 게임 데이터에서는 오래되거나 잘못된 정보를 제공할 위험이 있습니다.

이에 내부 데이터를 검색해 답변에 활용하는 RAG 구조를 설계하고, 질문 유형에 따라 검색 범위를 구분했습니다.

또한 정책상 노출해서는 안 되는 데이터가 응답에 포함되지 않도록 전처리와 후처리 규칙을 적용했습니다.

핵심 과제 03

제한된 비용에서의 기술적 의사결정

개인·비상업 프로젝트라는 특성을 고려해 무료 인프라를 중심으로 시스템을 구성했습니다.

  • Redis 캐시→PostgreSQL 기반 캐시
  • 외부 분석 도구 (메모리 제약)→자체 KPI 페이지

초기 설계에서 계획했던 Redis 캐시는 PostgreSQL 기반 캐시로 대체했고, 메모리 제약으로 사용할 수 없었던 외부 분석 도구 대신 자체 KPI 페이지를 구현했습니다.

이 과정에서 기술적 제약을 확인하고 설계 문서와 개발 작업에 변경 사항을 반영했습니다.
