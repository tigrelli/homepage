포트폴리오 목록 페이지 구조 설명

  1. 상단 필터 칩으로 카테고리(서비스 기획 / 개발 / 디자인 등) 구분, 우측 정렬 옵션(최신순 등) 배치.
  2. 카드에는 썸네일, 제목, 한줄 설명, 기술/역할 태그, 진행 기간을 표기해 목록만 봐도 프로젝트 성격 파악 가능.
  3. 카드 전체가 클릭 영역이며, 클릭 시 아래 상세 페이지로 이동.

포트폴리오 상세 페이지 구조 설명

  1. 상단 히어로: 프로젝트명, 기간·역할·팀구성·기술스택 메타 정보와 함께 라이브 데모 / GitHub / PRD·기획 문서 / Figma 등 실제 링크 버튼을 바로 노출.
  2. 좌측 고정 목차(TOC)로 개요 → 기획 → 디자인 → 개발 → 결과 섹션을 빠르게 이동(스크롤 스파이 방식).
  3. 기획 섹션이 핵심: PRD·기획서는 문서 카드 형태로 배치해 클릭 시 원본 문서(PDF/Notion 등) 새 탭 연결, IA는 별도 다이어그램 이미지로 정보구조를 시각적으로 제시.
  4. 디자인 섹션은 와이어프레임 → 실제 UI 스크린샷 순으로 갤러리 배치해 작업 과정을 보여줌.
  5. 개발 섹션은 기술 스택 태그와 핵심 구현 내용을 요약.
  6. 결과 섹션은 정량 지표(스탯 카드) + 회고 텍스트로 마무리, 하단은 이전/다음 프로젝트 내비게이션으로 연속 탐색 유도.

문의하기 페이지 구조 설명

  1. 좌측: 연락처, SNS, 응답 시간 안내 + 문의→미팅→견적→계약 4단계 프로세스로 기대치 설정.
  2. 우측: 이름/연락처/이메일/프로젝트 유형/예산/희망 일정/상세 내용/파일 첨부까지 받는 의뢰 폼.
  3. 하단 FAQ 아코디언으로 반복 질문(작업 범위, 비용 산정 방식 등)을 미리 해소.
